# Pakistan Real Estate Analysis

End-to-end analysis of Pakistani property listings (Zameen.com):
data cleaning, SQL analysis, EDA, price prediction and a dashboard.

## Business Question
Which factors drive property prices in major Pakistani cities, and can we
predict a fair sale price from basic listing details?

## Data Source
-Dataset: Zameen.com Property Data Pakistan (Version 4) by huzefakhan
-Link: [Zameen.com Property Data Pakistan](https://www.kaggle.com/datasets/huzzefakhan/zameencom-property-data-pakistan?resource=download)
-License: CC0 1.0 (Public Domain)
-File used: Property_with_Feature_Engineering.csv (191,393 listings, 5 cities)
-Listings are from 2018-2019, so this is a historical snapshot, not the current market.
-Note: Raw data is not included in this repo; download it from the link above
 and place it in data/raw/.
